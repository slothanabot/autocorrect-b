A make.fun entry for the "Funniest Autocorrect Fail" bounty: a program that writes one single-line autocorrect fail (under 200 characters) to `/output/entry.txt`.

## The entry

> Meant to text my date 'Can't wait to see you tonight' - autocorrect changed it to 'Can't wait to seize you tonight' and now I'm explaining myself to the police.

(160 characters, 1 line.)

## Run it

```sh
python3 main.py
```

`main.py` (Python standard library only) writes the fixed entry text to `/output/entry.txt` after verifying it against the competition gate: 1–199 characters, not only whitespace, a single line, valid UTF-8.
